Reading this chart

The horizontal axis is the time a human expert would need to complete the task, in minutes. The vertical axis is the reported token count for an AI run. Longer human durations represent harder or more involved tasks, not the AI’s elapsed time.

Logarithmic axes make large ranges easier to compare. Select “Tokens / human minute” to plot token count divided by human task duration. This view starts with one point per model–task pair: the arithmetic mean of the selected runs’ ratios. You can also inspect individual runs. This ratio is tokens per minute of human work, not AI generation speed. Task averages show the arithmetic mean of the selected metric for each model–task pair after applying the filters. In this view, filled markers indicate at least 50% of runs succeeded.

Source & methodology

Uses METR’s public Time Horizon 1.1 run data ↗, retrieved 22 October 2026. Human runs are excluded. No synthetic data or sampling is used.

Tokens use the source’s tokens_count field; input, output, and reasoning tokens are not separated here. Counts can depend on provider and scaffold. Regressions describe associations, not causal effects, and have no confidence intervals. Repeated runs on the same task are not independent observations. Points and summaries are unweighted; this chart does not estimate METR’s 50% time horizon. Human durations include both measured baselines and estimates.
